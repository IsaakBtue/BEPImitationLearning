## 🔧 Recent Fixes

### Issue 1: Task Re-registration Error ✅ FIXED
- **Problem:** Importing my_mjlab_project twice caused "Task 'goalkeeper' is already registered" error
- **Solution:** Updated __init__.py to check if task exists before registering
- **File:** src/my_mjlab_project/__init__.py

### Issue 2: Contact Buffer Overflow ✅ FIXED
- **Problem:** "narrowphase overflow - please increase nconmax" with 1020 envs + ball
- **Solution:** Set spec.nconmax=100, spec.njmax=500 in get_ball_spec()
- **File:** src/my_mjlab_project/tasks/goalkeeper_env_cfg.py

### Issue 3: CLI Argument Parsing ✅ FIXED
- **Problem:** --gpu-ids 0 failed (expected list format)
- **Solution:** Use --gpu-ids '[0]' or --gpu-ids None for CPU
- **Reference:** mjlab's tyro-based CLI requires list syntax

## ⚠️ Known Limitations

2. **No Motion File CLI Override:** Motion files hardcoded in config (unlike reference which accepts --motion-file)
3. **No Play/Evaluation Script:** Can use mjlab directly but custom wrappers in scripts/ are redundant
