# Session 2026-06-18 — HIM-PPO + full fix pass

## What this project is

`SimpleGoalKeeperObsHis` — Booster T1 foot-only goalkeeper using:
- **mjlab** (MuJoCo-Warp RL framework)
- **HIM-PPO** (Hybrid Internal Model PPO — obs history stacking + ball/region estimator sub-networks)
- **2-disc AMP** (left-step / right-step discriminators)
- **21-DOF headless T1** (head joints removed)

Target: match `Humanoid-Goalkeeper` (G1) architecture for the T1 robot with feet instead of hands.

## Issues diagnosed (from model_7200 analysis)

### Critical
| # | Issue |
|---|-------|
| 1 | **RSI 80% live-copy copied full state (root quat + vel)** from live envs that may have accumulated yaw drift, making the reset robot face the wrong direction. G1 copies DOF positions only. |
| 2 | **Ball estimator not implemented** — G1 has a dedicated MLP (history → 6D ball pos+vel) supervised by privileged critic obs. SGKObsHis passed ball directly in actor obs instead. |
| 3 | **History latent encoder not implemented** — G1 compresses history → 16D latent. SGKObsHis flattened 10×obs directly into a standard MLP. |
| 4 | **`est_loss` + `region_loss` missing from update** — G1 trains ball/region estimators with supervision losses. Not present in the original runner. |
| 5 | **No privileged critic observations** — no GT ball state or region ID in critic, so estimator supervision had no target. |

### High
| # | Issue |
|---|-------|
| 6 | **Region estimator not implemented as a network** — G1 has a 6-class subnet. Region ID was passed directly as an obs term instead. |
| 7 | **`std` shape bug** — `GaussianDistribution.params` returns std as `(21,)`. Rollout storage allocated `(T, 21)` not `(T, N, 21)`. `flatten(0,1)` produced `(T×21,)` = 1050 elements; batch indices up to 204799 caused silent CUDA OOB reads returning garbage floats (including negatives) into `get_kl_divergence`. Garbage old_std → NaN loss → NaN gradient → NaN `std_param` → `sample()` crash. |
| 8 | **`_raw_actor` not updated** — `PPO.get_policy()` returns `_raw_actor` (set once at PPO init). Replacing `self.alg.actor` left `_raw_actor` on the old MLPModel whose `distribution._distribution` was None → `output_std` property raised `AttributeError`. Also meant checkpoint save/load went to the old model. |

### Medium
| # | Issue |
|---|-------|
| 9 | **Play mode N=1 always gets group 1 (right disc)** — `assign_motion_types` with N=1: `ids[N//2:] = ids[0:] = 1`. All play-mode ball spawns went to robot's right (viewer's left), appearing as a left-side bias. |
| 10 | **`reset_base` redundant dead code** — base velocity config adds a standing-pose reset event; RSI then overwrites it. Wasted compute, caused confusion. |
| 11 | **`softstop` had no curriculum** — fixed weight 75.0. Other key rewards (stopball, footreach) had ramps; softstop didn't. |
| 12 | **Robot falls slowly after save, no termination** — `bad_orientation` (57°) and `base_height` (0.4 m) too lenient for a gradual post-dive topple. Robot could survive several seconds while falling without penalty. |

### Low
| # | Issue |
|---|-------|
| 13 | **`y_end` never crosses zero** — each disc always spawns balls on one side only; no center shots ever. |
| 14 | **`reset_ball_local_frame` (aerial ball) defined but never hooked** — only `reset_ball_rolling` is in use. |
| 15 | **`njmax` too low** — MuJoCo nefc overflow warnings during random-policy init (worst-case simultaneous contacts: all foot geoms + ball + self-collision). |

## All fixes applied (this session)

### `src/simple_goalkeeper_him/mdp/events.py`

**`assign_motion_types`** — N=1 (play mode) now picks a random group (0 or 1) instead of always group 1. Play runs will alternate disc sides.

**`MotionResetManager.reset()` — G1-faithful RSI:**
- `quat_out` initialised to identity `[w=1, 0, 0, 0]` for all envs.
- **80% live-copy**: copies DOF positions only (`joint_pos`). Velocities stay zero. Root uses `env_origins` (home XY+Z) with ±0.1 rad yaw jitter. Matches G1's `_reset_dofs` exactly: DOF positions from live env, `dof_vel=0`, root always at home.
- **20% NPZ**: unchanged — full frame (joints + root Z/quat/vel). Root XY always from env_origins (only Z overwritten). Matches original SGK 100% NPZ path exactly.
- Added explicit comment that NPZ root XY is discarded (only Z used).

**`_init_visibility_state`** — resets `_post_save_steps = 0` for resetting envs.

**`post_save_timeout_termination`** — new termination: fires 80 steps (~1.6 s at 50 Hz) after `_ball_is_behind` (ball deflected ≥ 0.2 m/s or crossed goal line). Prevents long episodes of a slowly-falling robot after a save.

### `src/simple_goalkeeper_him/tasks/goalkeeper_env_cfg.py`

- **`reset_base` removed**: explicitly popped alongside other base-config events.
- **`privileged` obs group added**: 7D, `history_length=1`, no noise. Layout: `[ball_pos_b(3) | ball_vel_b(3) | motion_type_id(1)]`. Stored in rollout buffer; read by runner for HIM supervision. Never fed to actor/critic models.
- **`softstop_curriculum` added**: weight ramps 50 → 75 → 100 at 0 / 2M / 4M steps.
- **`softstop` initial weight** set to 50.0 to match curriculum start.
- **`post_save_timeout` termination** added: 80 steps, `time_out=False`.
- **`njmax` 200 → 400**: overflow warnings peaked at 354 during random-policy init; settled once policy stabilises.

---

### `src/simple_goalkeeper_him/rsl_rl_amp/modules/him_actor.py` (new file)

G1-faithful HIM actor (`Humanoid-Goalkeeper/rsl_rl/rsl_rl/modules/actor_critic.py` ported to mjlab):

- `history_encoder`: full history → 16D latent
- `ball_estimator`: full history → 6D ball pos+vel estimate
- `region_estimator`: full history → 2-class (left/right) logits
- Actor input: `[cur_step_obs(86) | history_latent(16) | ball_est(6) | argmax(region)(1)]` = 109D → 512→256→128→21
- `obs_normalizer`: `EmpiricalNormalization(860)`, updates during training
- `distribution`: `GaussianDistribution(21, init_std=1.0, std_type="scalar")`
- **`output_distribution_params`**: expands `std` from `(21,)` to `(N, 21)` so rollout storage allocates `(T, N, 21)` and `flatten(0,1)` gives correct `(T*N, 21)` for batch indexing.
- Cached `_last_ball_est` and `_last_region_logits` after each forward for runner loss computation.

### `src/simple_goalkeeper_him/rsl_rl_amp/runners/him_amp_runner.py`

**`__init__`:**
- Reads `actor_obs_dim` and `num_one_step_obs` from env observations.
- Creates `HimActorModel` and installs it: `self.alg.actor = him` AND `self.alg._raw_actor = him`.
  - `_raw_actor` fix: `PPO.get_policy()` returns `_raw_actor`; not setting it left the old MLPModel there, causing `output_std` AttributeError and broken checkpoint I/O.
- Rebuilds `Adam` optimizer with HIM + critic params before adding disc param groups.

**`_update_with_amp`:**
- Extracts `_priv_flat = obs_flat["privileged"]` (safe try/except).
- After first actor forward pass: saves `_last_ball_est` and `_last_region_logits` before the smooth-loss second pass overwrites the cache.
- **`est_loss`**: `MSE(ball_estimator(history), gt_ball)` where `gt_ball = priv[:, :6]`.
- **`region_loss`**: `CrossEntropy(region_estimator(history), gt_region)` where `gt_region = priv[:, 6].long()`.
- **NaN guard**: if `loss` is non-finite, `optimizer.step()` is skipped and grads are cleared.
- **`std_param` clamp**: `actor.distribution.std_param.data.clamp_(1e-6, 100.0)` after each valid optimizer step.
- Loss dict extended with `est_loss` and `region_loss` for W&B logging.

## Architecture summary (post-fixes)

```
Obs history (10 frames × 86D = 860D)
        │
        ├─ history_encoder ──────────────────────→ latent (16D)
        ├─ ball_estimator ──→ est_loss (MSE vs GT) → ball_est (6D)
        └─ region_estimator → region_loss (CE vs GT) → argmax (1D)
                                                           │
        cur_step_obs (86D) ──────────────────────────────┤
                                                           ▼
                                              actor_mlp (109→512→256→128→21)
                                                           │
                                                     actions (21D)
```

Critic: standard MLPModel, stacked 10-frame history (860D), no privileged input.

Privileged obs (7D, history_length=1, current step only):
- Supervision target for ball_estimator: `ball_pos_b_true (3D)` + `ball_vel_b_true (3D)`
- Supervision target for region_estimator: `motion_type_id_priv (1D)` → 0 or 1

## Known remaining gaps

- **Center shots never trained**: each disc only sees balls aimed at its own side (left or right), y_end ∈ [0, y_end_hard] or [−y_end_hard, 0]. The robot never faces a ball aimed straight at the goal center.
- **`reset_ball_local_frame` (aerial ball) unused**: defined with y_end_max=1.5 m and height variation, but never wired into events.
- **HIM actor JIT/ONNX export not supported**: `as_jit()` and `as_onnx()` raise NotImplementedError. Deployment would need a separate export path.
- **Region estimator is 2-class** (left/right only), vs G1's 6-class. This is correct for 2-disc AMP but means the region encoding is very simple.
