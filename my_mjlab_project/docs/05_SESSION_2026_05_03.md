## Work Completed

### 1. Ball Physics Debugging & Fixes

**Problem:** Ball would not bounce when hitting the ground in play mode, despite multiple attempts to adjust physics parameters.

**Investigation:**
- Checked MuJoCo documentation for contact properties
- Discovered MuJoCo uses implicit solver with `solref` (solver reference) parameters, not `restitution` like PhysX
- Previous attempts only set `solimp` (impedance) but missed `solref` (the actual stiffness/damping parameters)

**Solution - Incremental tuning:**

*Attempt 1:* Initial configuration (no bounciness)
```python
geom.solimp = [0.001, 0.01, 0.001, 0.5, 2.0]
```
→ Result: No bouncing

*Attempt 2:* Added solref with soft contact
```python
geom.solref = [0.1, 0.15]  # soft contact, low damping
```
→ Result: Some bounce, inconsistent

*Attempt 3:* Increased bounciness
```python
geom.solref = [0.08, 0.05]  # softer, even lower damping
```
→ Result: Better bounce, but still cancelling sometimes

*Attempt 4:* Maximum elasticity (current)
```python
geom.solref = [0.05, 0.0001]  # stiff contact, near-zero damping
```
→ Result: Extreme bounciness, consistent

*Final tweak:* Adjusted margin/gap for better contact detection
```python
geom.margin = 0.001  # Contact detection at 1mm
geom.gap = 0.0001    # Include when dist < margin - gap
```

**Key insight:** The ground's contact properties also matter. The ball bounces well now because both the ball AND the ground have complementary properties.

### 2. Autonomous Play Fixes

**Problem:** Play mode still had motion-dependent code that crashed when motion command was removed.

**Fixes applied:**

1. **Removed motion-dependent reward terms** (6 terms)
   - motion_global_root_pos, motion_global_root_ori
   - motion_body_pos, motion_body_ori
   - motion_body_lin_vel, motion_body_ang_vel
   
2. **Removed motion-dependent termination term**
   - ee_body_pos (depends on motion command's anchor position)

3. **Implemented autonomous ball reset**
   - Created `reset_ball_autonomous()` function independent of motion data
   - Ball resets every 10 seconds with random trajectory
   - No dependency on motion command

**Result:** Play mode is now 100% autonomous. Policy receives:
- Ball position/velocity
- Joint state
- **No motion input whatsoever**

## Lessons from This Session

1. **MuJoCo vs PhysX:**
   - Different physics engines, different parameter conventions
   - restitution (PhysX) ≠ solref (MuJoCo)
   - Must understand underlying solver model

2. **Contact is pairwise:**
   - Ball bounciness depends on both ball AND ground properties
   - Tuning single object isn't sufficient

3. **Autonomous systems require careful decoupling:**
   - When removing motion dependency, must remove ALL references
   - Reward functions, terminations, resets all need separate implementations

4. **Color doesn't affect physics:**
   - As expected, visual representation is orthogonal to simulation

5. **Documentation is critical:**
   - Consolidated documentation prevents repeating past mistakes
   - Clear file organization helps future troubleshooting
